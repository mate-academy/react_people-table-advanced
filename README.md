# React People Table Advanced

Live Demo: https://heorhii-lytvynenko.github.io/react_people-table-advanced/

This project is a React + TypeScript people browser with URL-driven filtering and sorting.
The app opens on the People page by default and supports both table view and person-specific routes.

## Project Overview

- Users can filter people by sex, name, and centuries.
- Users can sort people by name, sex, born, and died columns.
- All filter/sort state is stored in URL search params for shareable links.
- Navigation within the People page keeps current search params.
- Filters are responsive and aligned for small screens.
